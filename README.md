# Sistema de Cadastro de Produtos

Projeto de terminal desenvolvido em Java para praticar orientação a objetos e manipulação de listas.

## Funcionalidades
- Cadastro de produtos
- Listagem de produtos
- Atualização de nome, preço e quantidade
- Exclusão de produtos

## Como executar
1. Tenha o JDK instalado.
2. Abra o terminal na pasta do projeto.
3. Compile: `javac Main.java`
4. Execute: `java Main`

Os dados ficam armazenados em memória durante a execução do programa.
